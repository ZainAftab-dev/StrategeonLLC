# Ecommerce Design Source

Use this file before any UI work in this React ecommerce project.

## Store Direction

- Build a polished electronics and networking ecommerce storefront, not a dashboard, admin panel, SaaS page, or generic landing page.
- The first screen must communicate a real tech shop: routers, mesh Wi-Fi, switches, adapters, cables, product specs, prices, cart action, and category browsing.
- Use electronics retail composition: crisp product modules, comparison-ready specs, category cards, compatibility notes, and clean technical hierarchy.
- Avoid generic AI visual habits: no purple gradients, no oversized rounded cards, no decorative blobs/orbs, no glassmorphism panels, no fake analytics widgets.
- Corners should be crisp or subtly softened. Default radius: `4px`; maximum radius: `8px` unless a native control demands otherwise.

## Visual Style

- Palette: white, cool gray, charcoal, networking blue, cyan, and restrained green/orange status accents. Do not use purple gradients.
- Typography should feel technical, retail, and trustworthy: strong sans headings, readable specs, compact product data.
- Use product images or product-like device renders for routers, mesh units, switches, adapters, extenders, and accessories.
- Buttons should be clear and retail-like: compact labels, strong hierarchy, visible hover/focus states.
- Product cards should show category, name, price, badge, rating/stock, and 2-3 meaningful specs such as Wi-Fi standard, port speed, PoE, coverage, or compatibility.

## Ecommerce UX Rules

- Multi-page storefront: Home, Shop, Collections, Support, and Product detail pages must navigate as pages, not only anchor-scroll sections.
- Mobile first: product discovery, filter/sort, cart access, and checkout CTA must be easy on a phone.
- Keep primary shopping actions visible: add to cart, view product, filter/sort, cart drawer.
- Use filters as shopping aids, not enterprise controls. Keep labels plain: Category, Search, Price, Sort.
- Cart state must be obvious and reversible. Include quantity changes, remove, subtotal, and checkout CTA.
- Product images need stable aspect ratios to prevent layout shift.
- Use semantic buttons/links, visible focus states, alt text, and 44px minimum hit targets.

## Pre-Delivery UI Check

- No purple gradient.
- No blob/orb decoration.
- No nested cards or dashboard-style stat panels.
- No hero section that hides the actual products or tech category entry points.
- No text overflow on mobile.
- Product grid, filters, cart drawer, and hero work at 375px and desktop widths.
- Color contrast and focus states are visible.
